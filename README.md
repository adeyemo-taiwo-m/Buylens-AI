## 📌 Executive Summary

High-value purchases across emerging markets (such as solar/inverter setups, power generators, computing equipment, and smartphones) are predominantly conducted through informal channels—WhatsApp quotations, Instagram DMs, Jiji listings, and physical markets like Alaba International and Computer Village in Nigeria.

In these environments, buyers encounter **information asymmetry, volatile pricing, counterfeit risks, and undisclosed omissions**.

**BuyLens AI** is **NOT** a marketplace, a generic chatbot, or an affiliate storefront. It is an **independent decision-support tool** that answers one singular question:

> ### **"Should I buy this?"**

## 🧭 The Decision Framework

Every analysis generated by BuyLens AI produces an actionable, 6-pillar decision report:

```
┌────────────────────────────────────────────────────────────────────────┐
│                          DECISION ARCHITECTURE                         │
└────────────────────────────────────────────────────────────────────────┘
          │
          ├── 1. Buy Score & Verdict (0–100 circular gauge & status pill)
          │
          ├── 2. Price Reality Check (fair corridor vs Lagos/Abuja retail averages)
          │
          ├── 3. Hidden Risk Audit (counterfeits, parallel imports, grey warranties)
          │
          ├── 4. Seller Interrogation Checklist (1-click WhatsApp message export)
          │
          ├── 5. Side-by-Side Trade-off Analysis (contextual alternative comparisons)
          │
          └── 6. Final Purchase Guidance (clear verification steps before paying)
```

## 🚀 Quick Start Guide

### 1. Prerequisites

Ensure you have **Node.js 20+** installed on your workstation.

```bash
node -v   # v20.18.0 or v22.12.0+ recommended
npm -v    # 10.9.0+
```

### 2. Clone and Install Dependencies

```bash
git clone https://github.com/your-username/buylens-ai.git
cd buylens-ai
npm install
```

### 3. Configure Environment Variables (Optional)

Copy the sample environment file:

```bash
cp .env.example .env.local
```

```env
# .env.local
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here
AI_API_KEY=your-openai-or-gemini-key-here
```

> [!NOTE]
> BuyLens AI includes a **built-in heuristic intelligence engine** calibrated for the Nigerian market. The application is **100% functional out of the box** even without an `AI_API_KEY`.

### 4. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 5. Production Build & Linting

```bash
# Verify code quality (0 errors, 0 warnings)
npm run lint

# Compile optimized Turbopack production build
npm run build

# Start production server
npm run start
```

## 🧪 Pre-Seeded Demonstration Case Studies

To ensure instant review and live presentation reliability, BuyLens AI includes three fully-modeled market case studies:

1. **Solar & Inverter System** (`₦850,000` / `₦4,850,000`):
   * *5kVA Hybrid Inverter + 5kWh/10kWh LiFePO4 Lithium Battery*
   * **Score**: `82/100` (`Worth Considering`)
   * **Audit Outcome**: High-efficiency prismatic cells, but flags unverified manufacturer warranty coverage and potential omission of copper cabling.
2. **Computing Equipment** (`₦2,400,000`):
   * *Apple MacBook Pro 16" M3 Pro (18GB, 512GB)*
   * **Score**: `91/100` (`Strong Buy`)
   * **Audit Outcome**: Battery health verified at 98%, price is 12% below Computer Village retail floor, clean MDM lock check.
3. **Power Generator** (`₦650,000`):
   * *Sumec Firman 3.5kVA Key-Start Petrol Generator*
   * **Score**: `68/100` (`Request More Info / Investigate`)
   * **Audit Outcome**: Price is suspiciously 12% below authorized distributor wholesale; triggers alert to verify 100% pure copper coil vs counterfeit aluminum windings.

## 🛡️ Trust & Independence Policy

* **Zero Sponsored Bias**: BuyLens AI does not accept seller listing fees, affiliate kickbacks, or promotional ranking payments.
* **Privacy Focused**: Uploaded receipts, quotation text, and images are processed for decision support and not shared with third-party merchants.
* **Transparent Verification**: Recommendations highlight risks, missing items, and trade-offs rather than dictating absolute instructions.
